# پرس (Pirs) — یاریی پرسیار

یاریی کویزی فرە-یاریزان: هۆست کویز هەڵدەبژێرێت، کۆد پیشان دەدات، یاریزانان دەچنە ژوورەوە و لەسەر خێرایی و دروستی خاڵ وەردەگرن.

## تایبەتمەندی

- دروستکردنی هەژمار + چوونەژوورەوە (ئیمەیڵ یان گووگڵ — کویزەکان دەمێننەوە)
- دروستکردنی کویزی خۆت (پرسیار + ٤ وەڵام + وەڵامی ڕاست)
- هۆست / چوونەژوورەوە بە PIN
- ٤ وەڵامی ڕەنگاوڕەنگ
- تایمەر و خاڵ بەپێی خێرایی
- لیدەربۆرد لە نێوان پرسیارەکاندا
- سێ زمان: کوردی / عەرەبی / ئینگلیزی
- یاری لە چەند تابێکدا (هۆست + یاریزان)

بەبێ Firebase: هەژمار/کویز لە هەمان ئامێردا دەمێنێتەوە.  
بۆ کلاد: بڕوانە `firebase/README.md`.

## دەستپێکردن

```bash
npm install
npm run dev
```

١. لە تابێکدا **دەستپێکردنی یاری** → کویز هەڵبژێرە  
٢. لە تابێکی دیکەدا **چوونەژوورەوە** بە هەمان PIN و ناوێک  
٣. هۆست یاری دەست پێ دەکات
