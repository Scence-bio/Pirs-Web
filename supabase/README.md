# Supabase بۆ پرس

بەبێ Supabaseیش ئەپەکە کاردەکات: هەژمار و کویز لە هەمان ئامێردا دەمێننەوە.

بۆ **کلاد** (هەمان هەژمار لە مۆبایل و کۆمپیوتەر):

1. پڕۆژەیەک دروست بکە لە [supabase.com](https://supabase.com)
2. لە **SQL Editor** ناوەڕۆکی `schema.sql` جێبەجێ بکە
3. لە **Authentication → Providers** ئیمەیڵ چالاک بێت
4. لە `.env` / GitHub Secrets:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY` (anon/public)
5. دووبارە بیلد / deploy بکە

دوای ئەوە کویزەکان و ژوورەکان لە کلاددا دەمێننەوە.
